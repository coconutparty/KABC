# KABC 경기 엔진 계산식 문서

대상 버전: Tech Demo 0.0.2

이 문서는 야구 경기 중 타자 공격 스탯, 투수/수비수 수비 스탯, 구종, 타격전략이 실제 판정에 어떻게 반영되는지 정리한다. 기준 코드는 `frontend/src/game/matchEngine.ts`, `frontend/src/game/config.ts`, `frontend/src/game/utils.ts`다.

## 1. 기본 스탯 보정

경기 중 대부분의 계산은 원본 스탯을 그대로 쓰지 않고 `effectiveStat()`을 거친다.

```text
컨디션 보정 =
  컨디션 >= 50이면 1.0
  컨디션 < 50이면 0.5 + 컨디션 * 0.01

감정 보정 =
  투지: 1.10
  태업: 0.90
  없음: 1.00

최종 스탯 =
  원본 스탯 * 감정 보정 * 컨디션 보정
```

예외:

- 투지는 컨디션 페널티를 무시한다.
- 체력은 직접 스탯을 깎지 않는다.
- 체력 30 이하 기믹은 이닝마다 컨디션을 깎고, 컨디션이 다시 스탯을 깎는 구조다.

## 2. 1구 판정 전체 흐름

현재 경기는 1구 단위로 다음 순서로 처리된다.

1. 투수 구종 선택
2. 구속 계산
3. 타자 타격전략 선택
4. 제구 판정
5. 스윙 여부 판정
6. 루킹 스트라이크 / 볼 / 사구 / 스윙 처리
7. 컨택 판정
8. 파울 / 헛스윙 / 인플레이 처리
9. 타구 방향 계산
10. 비거리 계산
11. 홈런 여부 판정
12. 타구 성질 판정
13. 담당 수비수 결정
14. 수비 성공 / 실책 / 안타 판정
15. 주루 및 득점 처리
16. 기록, 중계 로그, 판정 로그 기록

## 3. 구속 계산

구속은 투수의 `구속 스탯`과 구종의 구속 배율로 계산된다.

```text
판정 구속 =
  투수 최종 구속 * random(구종 최소 배율, 구종 최대 배율)

표시 구속 =
  round(판정 구속)
```

예:

- 구속 스탯 90
- 직구 배율 1.60~1.65
- 실제 구속은 144~148.5km/h 근처로 계산된다.

구속은 다음 판정에 영향을 준다.

- 스윙 여부
- 루킹/참기 판단
- 컨택 페널티
- 비거리 증가
- 일부 수비/송구 관련 스탯에서 수비수의 구속 스탯 사용

## 4. 제구 판정

제구 점수는 투수의 제구력, 주의력, 구종 제구 보정으로 계산된다.

```text
제구 점수 =
  투수 최종 제구력
  + 투수 최종 주의력 * 0.2
  + 구종 제구 보정
```

제구 결과는 `스트라이크존`, `볼`, `실투`, `위협구` 중 하나다.

| 제구 점수 | 스트라이크존 | 볼 | 실투 | 위협구 |
|---:|---:|---:|---:|---:|
| 90 이상 | 75% | 20% | 5% | 0% |
| 70~89 | 48% | 42% | 8% | 2% |
| 50~69 | 35% | 48% | 12% | 5% |
| 30~49 | 30% | 45% | 15% | 10% |
| 0~29 | 20% | 45% | 15% | 20% |

의미:

- 제구가 높으면 스트라이크존 비율이 늘고 위협구가 줄어든다.
- 평균급 제구에서는 볼이 꽤 발생한다.
- 실투는 타자가 치면 컨택 보너스를 받는다.

## 5. 선구안과 스윙 여부

타자의 선구안은 먼저 타격전략과 구종 보정을 받는다.

```text
전략 적용 선구안 =
  타자 최종 선구안 * 타격전략 선구안 배율
  + 구종 선구안 보정
```

이후 구속 압박이 들어간다.

```text
구속 압박 =
  max(0, 판정 구속 - 135) * 0.25

인식 점수 =
  전략 적용 선구안
  + 타격전략 인식 보정
  - 구속 압박
```

스윙 성향은 타격전략별로 따로 가진다.

```text
스트라이크성 공 스윙 확률 =
  clamp(
    60
    + 타자 최종 컨택 * 0.15
    + 타자 최종 장타력 * 0.08
    - 인식 점수 * 0.1
    + 전략 스윙 성향
    - 구속 압박 * 0.35,
    12,
    94
  )

나쁜 공 스윙 확률 =
  clamp(
    22
    + 전략 스윙 성향
    - 인식 점수 * 0.55
    + 구속 압박 * 0.08,
    4,
    88
  )
```

판정:

- 스트라이크존/실투인데 스윙하지 않으면 루킹 스트라이크.
- 볼/위협구인데 스윙하지 않으면 볼.
- 위협구를 스윙하지 않은 경우 사구 판정을 먼저 시도한다.

사구 확률:

```text
슬라이더 사구 확률 = (100 - 투수 원본 제구력) * 0.1%
기타 위협구 사구 확률 = 8%
```

## 6. 컨택 판정

스윙하면 컨택 판정을 한다.

```text
투수 구위 페널티 =
  max(0, 투수 최종 구위 - 65) * 0.22

구속 반응 페널티 =
  max(0, 판정 구속 - 145) * 0.10

나쁜 공 스윙 페널티 =
  위협구 스윙: -18
  볼 스윙: -12
  그 외: 0

실질 컨택 =
  타자 최종 컨택 * 타격전략 컨택 배율
  + 구종 컨택 보정
  - 투수 구위 페널티
  - 구속 반응 페널티
  + 나쁜 공 스윙 페널티
  + 실투 보정

실투 보정 =
  제구 결과가 실투이면 +10

컨택 성공률 =
  clamp(실질 컨택, 5, 95)
```

컨택 실패 시:

```text
파울 확률 =
  clamp(
    max(0, 60 - 전략 적용 선구안) * 0.2
    + max(0, 50 - 실질 컨택) * 0.1,
    5,
    35
  )
```

- 파울이면 스트라이크가 최대 2까지만 증가한다.
- 파울이 아니면 헛스윙 스트라이크다.
- 3스트라이크면 삼진이다.

## 7. 타구 방향 판정

컨택에 성공하면 타구 방향을 계산한다.

```text
방향 정확도 =
  전략 적용 선구안 * 0.45
  + 컨택 성공률 * 0.25
  - 투수 최종 제구력 * 0.2
  + 실투 보정
  + random(-10, +20)

실투 보정 =
  제구 결과가 실투이면 +20
```

방향 결과:

| 방향 정확도 | 결과 |
|---:|---|
| 75 이상 | 중앙 |
| 30~74 | 좌측 또는 우측 50:50 |
| 0~29 | 파울 |

방향이 파울이면 인플레이로 가지 않고 파울 처리된다.

## 8. 비거리 판정

```text
타자 장타 보정값 =
  타자 최종 장타력 * 타격전략 장타 배율

비거리 =
  18
  + 타자 장타 보정값 * 0.62
  + 컨택 성공률 * 0.18
  + 판정 구속 * 0.07
  - 투수 최종 구위 * 0.26
  + (컨택 성공률 - 컨택 판정 롤) * 0.26
  + 타격전략 비거리 보정
  + random(-12, +12)
```

장타력 문턱 보정:

```text
타자 장타 보정값 < 70:
  비거리 -= (70 - 타자 장타 보정값) * 0.65

타자 장타 보정값 >= 82:
  비거리 += (타자 장타 보정값 - 82) * 0.45
```

구종별 비거리 특수 효과:

- 직구: 비거리 * 1.10
- 팜볼: 비거리 * 1.10
- 커터: 10% 확률로 비거리 * 0.5
- 너클볼: 30% 확률로 비거리 * 0.5
- 싱커 땅볼 유도 성공 시 비거리 * 0.7
- 투심 땅볼 유도 성공 시 비거리 * 0.75

홈런 기준:

| 방향 | 홈런 기준 |
|---|---:|
| 중앙 | 120m 이상 |
| 좌측 | 100m 이상 |
| 우측 | 100m 이상 |
| 파울 | 홈런 없음 |

현재 구현상 홈런 여부는 방향과 비거리 기준으로 먼저 계산되고, 이후 타구 성질과 일부 구종의 땅볼 유도 처리가 이어진다. 이 때문에 홈런 밸런스를 더 정교하게 잡으려면 홈런 판정 순서를 별도로 재검토할 필요가 있다.

## 9. 타구 성질 판정

인플레이 타구는 `땅볼`, `플라이`, `라인드라이브`, `일반 타구` 중 하나가 된다.

```text
땅볼 확률 =
  clamp(
    8
    + max(0, 투수 최종 구위 - 타자 최종 장타력) * 0.35
    + 구종 땅볼 보정,
    3,
    28
  )

플라이 확률 =
  clamp(
    8
    + max(0, 타자 최종 장타력 - 투수 최종 구위) * 0.30
    + 구종 플라이 보정,
    3,
    25
  )

라인드라이브 확률 =
  clamp(
    12
    + max(0, 타자 최종 컨택 - 투수 최종 구위) * 0.18,
    6,
    24
  )
```

판정 순서:

1. 롤 < 땅볼 확률이면 땅볼
2. 다음 구간이면 플라이
3. 다음 구간이면 라인드라이브
4. 나머지는 일반 타구

타격전략이 번트면 타구 성질은 강제로 땅볼이 된다.

구종별 땅볼/플라이 보정:

| 구종 | 땅볼 보정 | 플라이 보정 |
|---|---:|---:|
| 직구 | -2 | +3 |
| 싱커 | +12 | -4 |
| 투심 | +8 | -3 |
| 커터 | +3 | -1 |
| 슬라이더 | +2 | +1 |
| 스플리터 | +8 | -3 |
| 포크볼 | +5 | -2 |
| 커브 | -2 | +5 |
| 너클커브 | -1 | +4 |
| 체인지업 | +2 | +1 |
| 서클체인지 | +3 | 0 |
| 팜볼 | -1 | +3 |
| 너클볼 | +2 | +2 |
| 스크류볼 | +3 | 0 |

## 10. 담당 수비수 결정

방향, 거리, 타구 성질로 담당 수비수를 정한다.

땅볼:

| 방향 | 거리 | 담당 |
|---|---:|---|
| 중앙 | 15m 미만 | 투수 |
| 중앙 | 15m 이상 | 2루수, 없으면 유격수 |
| 좌측 | 15m 미만 | 투수 또는 3루수 |
| 좌측 | 15m 이상 | 3루수, 없으면 유격수 |
| 우측 | 15m 미만 | 투수 또는 1루수 |
| 우측 | 15m 이상 | 1루수, 없으면 2루수 |

비땅볼:

| 조건 | 담당 |
|---|---|
| 20m 미만 | 포수, 없으면 투수 |
| 중앙 50m 이상 | 중견수 |
| 중앙 50m 미만 | 2루수, 없으면 유격수 |
| 좌측 50m 이상 | 좌익수 |
| 좌측 50m 미만 | 3루수, 없으면 유격수 |
| 우측 50m 이상 | 우익수 |
| 우측 50m 미만 | 1루수, 없으면 2루수 |

## 11. 수비 성공 판정

수비 판정 전 타구 품질을 계산한다.

```text
타구 품질 =
  clamp(컨택 성공률 - 컨택 판정 롤 + 50, 0, 100)
```

### 외야 플라이 / 깊은 타구

조건:

- 타구 성질이 플라이이거나
- 비거리 50m 이상

```text
수비 점수 =
  점프력 * 0.50
  + 주의력 * 0.25
  + 구속 * 0.15
  + 제구력 * 0.10

난이도 =
  비거리 * 0.50
  + 타구 품질 * 0.20
  + 방향 난이도

방향 난이도 =
  중앙 5
  좌/우 8

점프력 보너스 =
  점프력 90 이상: +12
  점프력 80~89: +8
  그 외: 0

기본값 =
  random(49, 57)

수비 성공률 =
  clamp(기본값 + 수비 점수 - 난이도 + 점프력 보너스, 5, 98)
```

### 내야 땅볼

```text
수비 점수 =
  주력 * 0.35
  + 주의력 * 0.30
  + 제구력 * 0.25
  + 구속 * 0.10

난이도 =
  타구 품질 * 0.35
  + 타자 속도 * 0.25
  + 비거리 * 0.20

기본값 =
  random(47, 54)

수비 성공률 =
  clamp(기본값 + 수비 점수 - 난이도, 5, 95)
```

### 짧은 타구

조건:

- 비거리 20m 미만

포수가 처리할 때:

```text
수비 점수 =
  포수 주의력 * 0.45
  + 포수 제구력 * 0.30
  + 포수 구속 * 0.25
```

투수가 처리할 때:

```text
수비 점수 =
  투수 주의력 * 0.45
  + 투수 제구력 * 0.35
  + 투수 구속 * 0.20
```

공통:

```text
난이도 =
  비거리 * 0.50
  + 타자 속도 * 0.25
  + 타구 품질 * 0.20

기본값 =
  random(53, 58)

수비 성공률 =
  clamp(기본값 + 수비 점수 - 난이도, 5, 95)
```

### 라인드라이브 / 일반 타구

```text
수비 점수 =
  주의력 * 0.45
  + max(주력, 점프력) * 0.25
  + 구속 * 0.15
  + 제구력 * 0.15

난이도 =
  타구 품질 * 0.70

기본값 =
  random(47, 57)

수비 성공률 =
  clamp(기본값 + 수비 점수 - 난이도, 5, 95)
```

## 12. 실책 판정

수비에 실패하면 실책 가능성을 따진다.

```text
실책 확률 =
  clamp(
    max(0, 60 - 수비수 주의력) * 0.3
    + max(0, 55 - 수비수 제구력) * 0.2,
    0,
    30
  )
```

실책이 아니면 안타가 된다.

안타 루 수:

```text
2루타 조건 =
  비거리 >= 90
  또는 라인드라이브이면서 비거리 >= 65

그 외 =
  1루타
```

## 13. 주루 판정

안타 후 추가 진루는 주자 속도, 타구 깊이, 타구 성질, 아웃카운트, 수비수 송구 스탯으로 처리된다.

```text
추가 진루 성공률 =
  clamp(
    주자 속도
    + 깊이 보정
    + 상황 보정
    - 수비수 구속 * 0.35
    - 수비수 제구력 * 0.20,
    5,
    92
  )
```

깊이 보정:

| 비거리 | 보정 |
|---:|---:|
| 90m 이상 | +22 |
| 75~89m | +12 |
| 50~74m | 0 |

- 장타 배율: 비거리와 타구 성질 판정에 영향을 준다.

## 16. 구종과 타격전략의 상성

### 직구 vs 타격전략

직구는 구속이 빠르고 비거리 보너스가 있다.

- 장점: 제구 +5, 구속 높음
- 단점: 타자 컨택 +5, 맞으면 비거리 * 1.10
- 상대 전략:
  - 장타를 노린다 / 당겨치기: 홈런 위험 증가
  - 공을 오래 본다: 빠른 구속 때문에 인식 점수는 깎이지만, 전략 자체의 인식 보정이 커서 볼 고르기에 유리

### 변화구 계열 vs 컨택형

슬라이더, 포크볼, 스플리터, 스크류볼은 컨택 보정을 낮춘다.

- 컨택 위주 전략은 이 페널티를 일부 상쇄한다.
- 장타 전략은 컨택 배율이 낮아서 헛스윙 위험이 커진다.
- 공을 오래 본다는 스윙을 줄여 볼넷 가능성을 높이지만, 스트라이크존에 들어오면 루킹 스트라이크도 늘 수 있다.

### 싱커/투심 vs 장타형

싱커와 투심은 땅볼 유도 성격이 강하다.

- 싱커: 30% 땅볼, 땅볼 시 비거리 * 0.70
- 투심: 25% 땅볼, 땅볼 시 비거리 * 0.75
- 장타 전략을 상대로도 홈런성 타구를 낮추는 방향으로 설계되어 있다.
- 단, 투심은 컨택 +5라 인플레이 자체는 늘 수 있다.

### 느린 변화구 vs 선구안

서클체인지와 팜볼은 선구안 보정을 깎는다.

- 공을 오래 본다 전략도 선구안 배율과 인식 보정으로 대응 가능하다.
- 선구안이 낮은 타자는 나쁜 공 스윙 확률이 오른다.
- 팜볼은 맞으면 비거리 * 1.10이라 실투성 위험이 있다.

### 너클볼

너클볼은 극단적 구종이다.

- 컨택 -15
- 제구 -15
- 체력 소모 2.0
- 30% 확률로 비거리 * 0.50

즉, 맞히기는 어렵게 하지만 볼/위협구/실투 위험과 체력 부담이 크다.

## 17. 현재 밸런스상 중요한 해석

### 타자의 출루는 세 갈래다

1. 선구안과 전략으로 볼넷을 만든다.
2. 컨택과 전략으로 인플레이를 만든다.
3. 수비 실패를 통해 안타가 된다.

즉 컨택 성공이 곧 안타는 아니다. 컨택 이후 방향, 비거리, 타구 성질, 담당 수비수, 수비 성공률을 모두 통과해야 한다.

### 투수는 세 방식으로 타자를 억제한다

1. 제구력/주의력으로 볼넷과 실투를 줄인다.
2. 구위로 컨택률과 타구 성질을 억제한다.
3. 구속으로 스윙 판단과 컨택을 압박한다.

### 수비수는 안타율을 직접 조절한다

수비수의 주의력, 제구력, 구속, 주력, 점프력은 수비 성공률에 직접 들어간다. 특히 현재 엔진에서는 수비 기본값 범위가 안타율 밸런스에 큰 영향을 준다.

### 타격전략은 단순 능력치 버프가 아니다

타격전략은 다음 네 축을 동시에 건드린다.

- 스윙 빈도
- 좋은 공/나쁜 공 인식
- 컨택 성공률
- 비거리와 주루

예를 들어 `공을 오래 본다`는 컨택을 조금 낮추지만, 스윙 성향을 크게 낮추고 인식 점수를 높여 볼넷과 루킹 판단에 영향을 준다. 반대로 `장타를 노린다`는 컨택을 깎고 장타/비거리를 올리며, 스윙 성향을 높여 공격적인 결과를 만든다.
